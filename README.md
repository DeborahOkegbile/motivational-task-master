# motivational-task-master

## Overview
An AI powered productivity application built using PartyRock for the AWS AI Practitioner Challenge.
The application helps users stay organised by extracting actionable tasks from emails and documents while providing AI-generated productivity support.

## Features

- Extracts actionable tasks from uploaded emails and documents
- Generates concise task summaries
- Provides productivity tips
- Generates motivational quotes based on user input
